Chi sono

Sono Enea, sviluppatore italiano. Lavoro soprattutto su Minecraft Java Edition, dal lato server e dal lato client.

Scrivo server engine con hotswap delle classi, framework che reggono interi network roleplay e client custom ottimizzati all’estremo. Sono lead developer di Next Roleplay e fondatore di Wave Studios, il mio studio creativo di sviluppo, build e grafica. In parallelo contribuisco a Horizon, Minecraft Java Edition riscritto in Rust.

01 — Server engine

Obsidian

Il mio server engine per Minecraft Java Edition. I moduli .obs sono firmati e fanno hotswap delle classi: si deployano live in produzione, a server acceso, senza riavvii e senza che i player se ne accorgano. Rollback automatico, JVM già tunata e un pannello di gestione integrato.

  • Java
  • Hotswap a runtime
  • Zero downtime
  • Rollback automatico
  • Pannello di gestione
02 — Framework roleplay

Next Roleplay

Il framework proprietario che regge l’intero network Next Roleplay: core, moduli, sistemi di gioco e tool interni. Ne curo architettura, sviluppo e manutenzione, dal primo modulo all’ultimo refactoring.

  • Lead Developer
  • Java
  • TypeScript
  • Architettura modulare
  • Sistemi di gioco

06 — Pannello di controllo

Helm

Il pannello di controllo dei server di gioco Pelican: ogni server in tempo reale con stato, CPU, RAM, disco e uptime, console con log colorati e comandi, avvio e spegnimento con conferma, giocatori online. Accesso con Discord o Telegram e, dietro, un backend che comanda il VPS in SSH.

  • Node.js
  • SSH
  • Pannello

07 — Sito web

Evolución Canaria

Un sito costruito da zero per il partito Evolución Canaria: gerarchia, elezioni, propaganda, eventi e proposte, con un pannello in cui ogni contenuto viene salvato e lo vedono subito tutti i visitatori. Area riservata con Discord o Telegram, nessun framework e nessun build step: una pagina sola, servita com’è.

  • HTML
  • CSS
